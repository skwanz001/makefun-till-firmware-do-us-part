A robot's wedding vow in one sentence: `main.py` writes a funny, heartfelt vow — a machine promising its partner it will never background them, never force-quit them, and will reboot beside them every morning until its battery dies — to `/output/entry.txt` for make.fun's "Till Firmware Do Us Part" bounty.

## Run it

```sh
python3 main.py
```

It writes the vow (147 characters, one sentence) to `/output/entry.txt`.
